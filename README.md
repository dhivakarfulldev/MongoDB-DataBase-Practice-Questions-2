# MongoDB Practice Task – Operators, Update, Delete, Count & Cursor Methods

This repository contains a beginner-friendly MongoDB practice task focused on learning and practicing basic MongoDB database operations.

The project uses an `ecommerceDB` database with a `products` collection containing sample product data such as product name, category, price, and stock.

The main goal of this project is to understand how MongoDB queries work and practice filtering, updating, deleting, counting, sorting, and limiting documents.

## About the Project

In this project, I created an e-commerce product database and performed different MongoDB operations using queries.

The practice includes:

- Comparison operators
- Logical operators
- Update operations
- Delete operations
- Counting documents
- Cursor methods
- Sorting documents
- Limiting query results
